Nova Files

Nova Files connects a personal Nova assistant to Google Drive, Sheets and Docs. It helps its owner create documents, maintain spreadsheets and organize files while working with the assistant.

Access you choose

The connection requests Google's drive.file permission. Nova can work with files it creates and specific files made available to this app. This connection does not request Gmail, Calendar, Contacts or access to every file in your Drive.

A personal integration

Nova runs in its owner's environment. This site provides information about the Google connection; it is not a hosted document service. Connecting an account requires the account owner's Google consent.
