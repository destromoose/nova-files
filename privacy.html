Nova Files

Privacy policy

Effective September 14, 2026

Nova Files is a personal Google Workspace connection for the Nova assistant. Its purpose is to let its owner create and work with selected Google Drive files, spreadsheets and documents.

Data accessed and why

The connection requests https://www.googleapis.com/auth/drive.file. It accesses the contents and metadata of files created by the app or specifically made available to it, as needed to perform the owner's requested tasks. Depending on the task, metadata can include file identifiers, names, folder relationships and ownership details. The connection does not request Gmail, Calendar, Contacts or blanket access to the owner's Drive.

Storage and processing

OAuth credentials and refresh tokens are stored in the owner's Nova environment with restricted file permissions. Documents remain in Google Drive unless the owner requests local copies. Nova can retain relevant task content in its local session history, working files and configured backups.

When the owner asks Nova to analyze or transform file content, relevant content may be sent to the AI provider configured in their Nova installation to carry out that request. Provider processing is subject to the owner's provider configuration and that provider's terms. This information website does not receive Google credentials or document contents.

Use and sharing

Nova Files uses Google data to provide the requested file features. It does not sell Google user data, use it for advertising, or use Google Workspace data to develop, improve or train generalized AI or machine-learning models. Files are not made public by this connection. Any requested sharing of a file is a separate action.

Nova Files' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

The owner controls Nova's local storage, history and backups. Revoking the connection stops future authorized API access; it does not automatically delete existing Google files or local copies. The owner can remove local copies and backups through their storage controls and delete Google files in Drive.

Access can be revoked at any time from Google Account connections. Credentials are kept only while needed for the configured connection and any owner-controlled backups.

Contact and changes

For questions or requests, contact the maintainer. Do not include credentials or private documents in public issues. Changes to this policy will be reflected on this page with an updated effective date.
